  • Full local control over models, tools, and optional external providers

02 / SECURITY, PRIVACY & GOVERNANCE

Shared hardware shouldn’t mean shared secrets.

Running a model locally is only half the story. OpenMettle engineers multi-user isolation across the database, the identity boundary, the run queue, and the inference proxy itself.

S-01 ADR 0027 · ADR 0044

Per-User Chat Lockdown & Prefix-Cache Isolation

Every conversation, artifact, and memory record is private to its creator by default — even inside shared projects, and even account administrators gain no implicit access to another person’s unshared items. Explicit sharing uses revocable grants, returning 404 concealment for unshared or out-of-scope targets.

At dispatch, OpenMettle’s own inference proxy rejects caller-supplied SGLang routing keys (cache_salt, extra_key, session_id, rid, lora_path) and injects a scoped cryptographic cache_salt so upstream KV prefix caches do not bleed across users or private chats on qualified backends.

S-02 ADR 0044 · MIGRATION 35

Four-Point Family & Study Protection Rules

IANA timezone- and DST-accurate quiet hours, study-hour model allowlists, and per-user or group model switches are evaluated by one authoritative PostgreSQL policy function, with optional user-level schedule overrides.

Rules are enforced independently at four checkpoints — API admission and preview, worker claim and step recheck, database round handoff, and proxy dispatch — failing closed whenever OIDC group evidence is stale, revoked, or missing.

S-03 ADR 0003 · 0022 · 0030 · 0044

Least-Privilege Database & Identity Isolation

Clean-room Rust services run over PostgreSQL 18 using four disjoint, non-DDL, non-DELETE runtime roles — openmettle_api, dedicated session-issuing openmettle_issuance, openmettle_worker, and openmettle_gateway for dispatch and usage settlement — checked automatically on every migration.

OIDC/SSO login uses local operator identity approval gates and one-time home invitation codes, while every inference round carries a single-use 32-byte bearer whose plaintext never touches the database (only its SHA-256 digest is stored and checked).

S-04 ADR 0035 · 0040 · 0041 · 0024

Tool Approvals, Quotas & Verifiable Auditability

Human-in-the-loop tool approvals are cryptographically bound (SHA-256) to canonical arguments, tool version, exact destination, and live policy revisions; opt-in YOLO mode stays strictly policy-gated and cannot bypass immutable human confirmation classes.

Exact-integer transactional quotas govern tokens, cost micro-units, storage bytes, and device slots. Soft-delete grace periods, operator retention holds, an append-only SHA-256 hash-chained deletion journal with a fail-closed restore barrier, and value-free, PII-free structured telemetry (export off by default) complete the governance model.

03 / SERVING & PLATFORM ENGINEERING

Cutting-edge inference meets dependable execution.

Fast local GPUs shouldn’t come at the cost of fragile chats or stranded VRAM. OpenMettle pairs AMD-first ROCm serving research with durable, server-owned run orchestration.

AMD-FIRST ROCm & RDNA4 · ADR 0042

Demand-Driven Elastic KV Cache & Curated SGLang Serving

Our curated SGLang serving stack (OpenMettle/sglang, openmettle-serving) combines HIP virtual-memory Elastic KV Cache, FP8 attention caching, MXFP4 quantization, and speculative decoding research tuned for AMD GPUs first.

Active chats stay protected inside a physically backed base while spare VRAM is lent to a dynamically mapped prefix-cache tail. When image, video, or accelerated tool workloads arrive, a fenced PostgreSQL capacity controller requests a safe shrink and waits for confirmed multi-rank VRAM release before granting the GPU.

GPU-independent core: openmettle-core runs on CPU alone, integrates optional GPU packages through Kubernetes DRA, plans qualified NVIDIA profiles, and connects cleanly to user-configured external OpenAI-compatible backends.

ADR 0032 · 0033 · 0034

Durable Leased Runs & Replayable SSE

PostgreSQL backs a fair SKIP LOCKED work queue with fenced worker leases, execution deadlines, and crash recovery that never blindly replays uncertain side effects. Runs survive browser or mobile disconnects and resume from any API replica via HMAC-signed SSE event cursors.

ADR 0036

Non-Destructive Branch Graphs

Conversations are stored as parent-linked immutable message graphs. Editing a prompt or retrying a reply forks a new branch without erasing history, paired with layered model-and-preset configuration and explicit, honest context budgets.

WEB · MOBILE · CLUSTER · IDE

Coherent Delivery Across Interfaces

Backend APIs and OpenAPI 3.2 contracts lead step 1 ahead of the Flutter web and mobile client in step 2 (openmettle-app). Generic Kubernetes/Helm packaging with deny-all NetworkPolicies lives in openmettle-deploy, alongside our local IDE and CLI coding agent (openmettle-acp).
